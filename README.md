# SpringAI

A repository containing Python scripts and applications for building LLM-powered systems, Retrieval-Augmented Generation (RAG), and AI chatbots.

## 📁 Repository Structure

* **`ragchatbot.py`**: Implementation of a RAG-based conversational chatbot.
* **`RAG.py`**: Core Retrieval-Augmented Generation pipeline setup.
* **`LLM Application.py`**: Basic setup and execution of Large Language Model workflows.
* **`Building.py`**: Utility and helper functions for environment setup and model building.

## 🚀 Getting Started
